# 🛒 Tienda "La Caserita" - Plataforma E-Commerce

Bienvenido al repositorio oficial de **Tienda "La Caserita"**, una plataforma e-commerce moderna, rápida y adaptable diseñada para compras de abarrotes, productos frescos y artículos para el hogar en línea.

---

## 🌟 Características Principales

- **🛍️ Catálogo Interactivo de Productos:** Navegación por categorías (Carnes, Verduras, Abarrotes, Bebidas, Lácteos, Panadería, Congelados, Dulces, Limpieza).
- **☕ Secciones por Momentos del Día:** Filtros rápidos para Desayuno, Almuerzo, Lonchera y Cena.
- **🛒 Carrito de Compras en Tiempo Real:** Gestión de productos, cálculo dinámico de subtotal, envío y total.
- **💳 Múltiples Métodos de Pago:** Integración visual para Pago en Efectivo y Yape.
- **🔒 Autenticación Segura y Google Auth:** Inicio de sesión con correo/contraseña o cuenta de Google (Google Sign-In).
- **👤 Panel de Usuario:** Historial de compras, gestión de direcciones de entrega e información personal.
- **⚙️ Panel de Administración:** Gestión de inventario, stock, adición/eliminación de productos y categorías en tiempo real.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5, CSS3 Moderno, JavaScript (ES6+), jQuery, Font Awesome 6.
- **Backend:** Node.js, Express.js.
- **Base de Datos:** MongoDB con Mongoose.
- **Seguridad:** JWT (JSON Web Tokens), bcrypt hashing, Google Auth Library.
